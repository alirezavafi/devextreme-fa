DevExtreme Multi-Calendar

Live visual tests for the fork that teaches DevExtreme to display, accept and group dates in Persian (Jalali), Hijri (tabular), Hijri (Umm al-Qura) and custom calendars.

Every page has a calendar, language and theme picker at the top. Switching the calendar changes only what you see — the stored values stay native proleptic-Gregorian Date objects.
